### Focus

- **Documentation tooling.** Sphinx themes and Java API reference built from real compiler output, not regex.

- **Cloud platforms.** AWS data pipelines and serverless APIs.
- **Observability.** Monitoring with Grafana, Nagios and Icinga, from plugins to dashboards.
