I build developer tools, mostly for documentation.

- [Lumina](https://r4sky0.github.io/sphinx-lumina-theme/), a Sphinx theme with dark mode and instant search
- [sphinx-java-autodoc](https://r4sky0.github.io/sphinx-java-autodoc/), Java API docs for Sphinx, built from real compiler output
- [apick](https://github.com/r4sky0/apick), browse and call OpenAPI endpoints from the terminal
- [nagios_check_paloalto](https://github.com/r4sky0/nagios_check_paloalto), a Nagios and Icinga plugin for Palo Alto firewalls
